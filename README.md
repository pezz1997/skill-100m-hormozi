# 100M Business Consultant - Skill Hormozi

Skill per Claude (Cowork) basata sui 12 playbook $100M di Alex Hormozi.

## Come installare questa skill

1. Copia la cartella `100m-business-consultant` nel percorso:
   ```
   <tua_cartella_cowork>/.claude/skills/100m-business-consultant/
   ```

2. La struttura deve essere:
   ```
   .claude/
   └── skills/
       └── 100m-business-consultant/
           ├── SKILL.md
           └── references/
               ├── affiliate.md
               ├── branding.md
               ├── fast-cash.md
               ├── goated-ads.md
               ├── hooks.md
               ├── lead-nurture.md
               ├── ltv.md
               ├── marketing-machine.md
               ├── money-models.md
               ├── price-raise.md
               ├── pricing.md
               └── retention.md
   ```

3. Riavvia Claude / Cowork. La skill sarà disponibile automaticamente.

## Trigger principali

La skill si attiva quando parli di:
- Analisi business, scaling, fatturato, profitto
- Prezzi, LTV, Grand Slam Offer, offerte premium
- Ads, hook, branding, lead generation
- Hormozi, $100M, revenue optimization
